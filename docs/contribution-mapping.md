# Contribution Mapping

This document maps the project files to the specific team roles responsible for their development and maintenance.

- **`index.html` → UX/UI Designer (Ayse)**
  - Responsible for the structural HTML framework, DOM elements, and semantic layout of the dashboard.

- **`css/styles.css` → UX/UI Designer (Ayse)**
  - Responsible for the dark theme aesthetic, responsive CSS grids, component styling, and animations.

- **`js/data.js` → Lead Developer (Mert) / QA/Tester (Elif)**
  - Mert defined the schema and data models. Elif populated the realistic mock data to ensure edge cases were represented for testing.

- **`js/logic.js` → Lead Developer (Mert) / Operations Lead (Can)**
  - Mert built the core filtering, state management, and DOM update loops. Can contributed the dynamic data refresh and pipeline integration logic.

- **`js/charts.js` → UX/UI Designer (Ayse) / Lead Developer (Mert)**
  - Ayse designed the pure SVG/HTML charting concepts, while Mert implemented the logic to dynamically map data into the visual elements.

- **`docs/roles.md` → Project Manager (Ali)**
  - Defined the team structure and task distribution.

- **`docs/test-plan.md` → QA/Tester (Elif)**
  - Established testing criteria and incident response workflows.

- **`docs/risk-register.md` → Risk Manager (Zeynep)**
  - Maintained the active registry of identified system risks and mitigation strategies.

- **`docs/stakeholders.md` → Project Manager (Ali)**
  - Mapped out the target audience and usage patterns for the dashboard.
