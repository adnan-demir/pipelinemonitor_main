# Stakeholders Map

Key stakeholders who consume the data generated by the ProjectPulse monitoring tool:

## 1. Executive Management
- **Interest:** High-level project progress, timeline deviations, overall health.
- **Dashboard Usage:** Overview Tab (Progress percentage, Delayed task count).

## 2. Engineering Leads
- **Interest:** Technical blockers, pipeline stability, code integration.
- **Dashboard Usage:** Pipeline Analytics, Pipeline Health Metrics.

## 3. Product Owners
- **Interest:** Feature completeness, UX clarity, usability scores.
- **Dashboard Usage:** Team Analytics, UX/UI Inspection panels.

## 4. Security & Compliance Officers
- **Interest:** System errors, security audit tasks, access control.
- **Dashboard Usage:** Risk Analytics, Error logs.
