# ProjectPulse – Team & Pipeline Health Monitor

ProjectPulse is an interactive, zero-dependency command center designed to monitor team contributions, pipeline health, and code integration metrics.

## Team Structure
The project was built by a collaborative 6-person team:
- **Project Manager:** Ali
- **Lead Developer:** Mert
- **QA/Tester:** Elif
- **UX/UI Designer:** Ayse
- **Risk Manager:** Zeynep
- **Operations Lead:** Can

## Role Responsibilities
Each team member owned specific domains of the project. Management focused on timelines and risks, Development built the interactive logic and styling, and QA/Operations ensured system stability. For a detailed breakdown of individual responsibilities, see [Roles Documentation](docs/roles.md).

## Development Process
We utilized an Agile-like iterative process, splitting work into Foundation, Functionality, and Polish phases. Parallel development was achieved by separating data models (`data.js`), rendering logic (`logic.js`), and analytics (`charts.js`). Constant testing and risk analysis ensured stable feature delivery. For full details, see the [Development Process](docs/development-process.md) and the [Team Activity Log](docs/team-activity.md).

## Contribution Mapping
Files were strictly mapped to specific role specializations to mirror a professional development environment:
- **UI/UX:** `index.html`, `css/styles.css`
- **Logic & Data:** `js/logic.js`, `js/data.js`, `js/charts.js`
- **Documentation:** `docs/test-plan.md`, `docs/risk-register.md`, `docs/stakeholders.md`

See the full [Contribution Mapping](docs/contribution-mapping.md) for details on file ownership.

## Running the Application
Simply open `index.html` in any modern web browser. No external dependencies, local servers, or APIs are required.
